# ExtractKindleVoca
- Extract Kindle Voca from VocaBuiler to CSV file
- using Windows C#
- [Release](https://github.com/soorichu/ExtractKindleVoca/ExtractKindleVoca/bin/x64/) download release.zip, extract and run ExtractKindleVoca.exe
- For Windows x64 and Amazon Kindle Device (No Android Kindle App)
